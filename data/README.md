# Dataset
`data/raw` is populated by `python src/download_dataset.py`.

Source used by the downloader:
Sukma Adhi Wijaya, **Weld Quality Inspection - Instance Segmentation**, Kaggle.
Documented classes: Bad Welding, Crack, Excess Reinforcement, Good Welding, Porosity, Spatters.
License shown on the dataset page: CC0 Public Domain.

The project does not fabricate an Undercut class because this selected dataset does not document one.
